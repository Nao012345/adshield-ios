# iOS 版 Brave 互換性と本番採用ルール

`scripts/filterlib.py` がこの表どおりに検査し、本番（`filters/`）で「不可」の構文はビルドを止める。
根拠は [research.md](research.md)。実機での確認状況は [verification.md](verification.md)。

## ルールを書くときの決まり

- ネットワークルールには原則 `$third-party` を付ける（配信事業者自身のサイトを壊さない）。
- 動画サイト（`filters/video/`）ではネットワーク遮断をしない。テスト `test_video_lists_never_block_network` で強制。
- ログイン・決済・CAPTCHA・動画配信の URL は `tests/fixtures/must_not_block.txt` に入れて、遮断されないことをテストする。
- 上流のルールを使う場合は `! @source: <id>` を前に書く。

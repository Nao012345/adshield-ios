# 実機検証の記録

**iOS 版 Brave での実機テストを、Windows のブラウザテストで代わりにしてはいけない**（指示書 9）。
実施していない項目は「未検証」のままにする。

## 記録の書き方

各テストで、次を記録する: 日付 / iPhone 機種 / iOS バージョン / Brave バージョン /
「トラッカーと広告のブロック」の設定（標準・アグレッシブ）/ 登録したリスト / Japanese リストのオン・オフ / 結果 / 備考。
動画広告は「広告が出た条件」（ログイン有無、再生した動画、時刻）と「適用後の結果」を書く。
